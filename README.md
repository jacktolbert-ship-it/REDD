# DrinkRedd

Website for **REDD** — a beetroot-based nitric oxide supplement designed for endurance athletes. Single-serve powder sachets formulated to support blood flow, oxygen delivery, and athletic performance.

## About

REDD is a sports nutrition product built around beetroot extract, a natural source of dietary nitrates that convert to nitric oxide in the body. Research has linked nitric oxide supplementation to improved endurance, reduced oxygen cost during exercise, and faster recovery.

This site serves as the brand's landing page and product information hub.
